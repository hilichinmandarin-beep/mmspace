# 喝吧! 飲料店（華語教學用）

仿照購物 App 的飲料店網站，讓學生用中文點手搖飲。不需要安裝任何東西，直接用瀏覽器打開 `index.html` 就能用（放到 GitHub Pages 也可以）。

## 檔案

| 檔案 | 用途 |
|---|---|
| `data.js` | **老師主要改這個**：店名、顏色、分類、商品、價格、詞彙表（拼音／英文）、教學設定 |
| `index.html` / `app.js` | 學生用的商店 |
| `teacher.html` / `teacher.js` | 老師後台 |
| `common.js` / `style.css` | 共用的程式和外觀 |
| `apps-script.gs` | 貼到 Google 試算表，用來收全班訂單 |

## 教學功能

- **拼音／EN**：上方工具列的開關，所有商品、分類、選項、按鈕都會顯示拼音或英文。
- **🔊 點字發音**：打開後，點任何中文字都會唸出來。商品頁的 🔊 按鈕隨時都能用。
- **用中文點飲料**：結帳前，學生要看圖（杯數、M/L、🍬 甜度 %、🧊 冰塊 %）說出或打出整句話，例如：
  > 我要兩杯珍珠奶茶，大杯、半糖、少冰。

  - 順序不限，標點和空格不算，打簡體字、阿拉伯數字（2 杯）也可以。
  - 按「檢查」會告訴學生哪一部分錯了（數量、飲料、大小、甜度、冰塊）。
  - 提示：拼音、English、聽一聽、看答案。用了幾次提示、試了幾次都會記錄給老師看。
  - 🎤 用說的：Chrome、Edge 可以用語音輸入。
  - 不想練習造句：把 `TEACHING.requireSentence` 改成 `false`。

## 換內容

- **新增商品**：在 `PRODUCTS` 加一行，再到 `WORDS` 加上它的拼音和英文。
- **用真的照片**：把照片放到 `images/` 資料夾，商品加上 `img: "images/檔名.jpg"`。沒寫 `img` 的商品會自動畫一杯飲料（用 `look` 設定顏色和配料）。
- **換顏色**：改 `SHOP.color`；學生也能在「我」頁面自己換。可選的顏色在 `THEMES`。
- **換店名**：改 `SHOP.name`、`SHOP.slogan`。

## 老師後台

打開 `teacher.html`（「我」頁面最下面也有連結）。可以看到：

- 要做的飲料（同樣的飲料、甜度、冰塊合在一起算杯數）
- 每個學生的訂單數、杯數、花費、嘗試次數、提示次數
- 全部訂單

### 收到全班的訂單（Google 試算表）

沒設定的時候是**單機模式**：訂單只存在學生自己的瀏覽器，後台也只看得到同一台電腦的訂單。要收全班的訂單：

1. 開一個新的 Google 試算表 → 選單「擴充功能」→「Apps Script」。
2. 把 `apps-script.gs` 的內容整個貼上，把 `TEACHER_KEY` 改成你的密碼，儲存。
3. 右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」。
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，第一次會要你授權，授權後複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。
5. 打開 `data.js`，貼到 `TEACHER.scriptUrl: "這裡"`。
6. 打開 `teacher.html`，輸入密碼，按「重新整理」。

學生的訂單會一行一行出現在試算表裡；想清空就直接刪掉試算表的資料列（第一行標題留著）。

> 修改 `apps-script.gs` 以後，要到「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」，網址才會用到新的程式。
